# Скиллы для прототипирования архитектуры уровней в Unreal Engine 5.8

В комплекте **три самостоятельных скилла** (каждый каталог содержит собственный `SKILL.md` и необходимые `references/`). Инструкции внутри скиллов написаны на английском языке для последовательной работы LLM с англоязычным API Unreal MCP; пользователь может ставить задачи по-русски.

## 1. `cubegrid-plan-build`

Назначение: создание архитектурного blockout по плану сверху (картинка, схема). Сначала извлекает стены как сегменты с реальными координатами, проёмы внутри сегментов и вертикальные переходы; затем переводит план в смежные модули CubeGrid. Особое внимание уделяется наклонным стенам и кривым: поворот сетки **для отдельной сессии**, ступенчатые приближения и аппроксимация дуг хордами выбираются в зависимости от важности формы и проходимости.

Файлы: `SKILL.md`, `references/CUBEGRID-MCP.md`, `references/PLAN-INTERPRETATION.md`, `references/BUILD-RECIPES.md`, `scripts/grid_math.py`, `scripts/example_plan.json`, `tests/test_grid_math.py`.

Вычислительный помощник (не подключается к MCP и ничего не меняет в редакторе):

```bash
python cubegrid-plan-build/scripts/grid_math.py cubegrid-plan-build/scripts/example_plan.json -o planned_cells.json
```

## 2. `ue-selection-describe`

Назначение: описание **выделенных** Actor/Component в открытом уровне — тип/роль модуля, габариты, материал каждого подтверждённого слота/поверхности, проёмы, повторяющиеся элементы, способ масштабирования.

Результат в редакторе Unreal:

1. `ST_LevelMaterialRow` — настоящий ассет `Structure` с полями `Material`, `WhereUsed`, `VisualDescription`.
2. `DT_LevelMaterials` — настоящий ассет `DataTable` на основе этой структуры; материалы заносятся по смысловым ролям, с сохранением существующих записей.
3. `DA_<ObjectId>` — отдельный настоящий `DataAsset` для описания каждого логического архитектурного объекта. Его тип определяется `UDataAsset`/`UPrimaryDataAsset`-совместимым классом с необходимыми свойствами.

## 3. `cubegrid-concept-build`

Назначение: архитектурный blockout по одному или нескольким концепт-артам с указанным направлением наблюдения, с опциональным планом (картинка/ASCII) и **предоставленной пользователем** таблицей `DataTable` материалов.

Модель связывает общие ориентиры на видах, реконструирует минимально обоснованную геометрию, учитывает видимые/невидимые стороны и перспективу, расставляет материалы согласно `WhereUsed`, затем строит отдельные модули CubeGrid. При наличии плана использует его для XY-топологии, а концепты — для высот, фасадов и материалов.

## Технические ограничения MCP

Список методов CubeGrid взят только из предоставленного `CubeGridToolset.h`. Он поддерживает создание **пустой** сессии, выбор прямоугольника, выдавливание/вычитание, материалы, UV-масштаб, угловой режим, подтверждение или отмену. В отличие от интерактивного редактора, API не заявляет произвольного поворота каждого прямоугольника, работы по уже выделенному мешу, глобального undo или сохранения пакетов.

Владелец скиллов подтвердил наличие **других MCP-инструментов Unreal Editor** для чтения ресурсов, выделения, DataTable, ассетов и сохранения. Поэтому скиллы предписывают модели определить их действительные имена и сигнатуры при выполнении. В комплекте не выдуманы названия отсутствующих методов.

## Использование

Каждый каталог можно установить как отдельный skill, сохранив его внутренние `references/` и, для первого скилла, `scripts/`. Если все каталоги установлены вместе, скиллы могут использоваться последовательно:

- По плану построить геометрию через `cubegrid-plan-build`.
- Выделить созданные Actor и каталогизировать их через `ue-selection-describe`.
- Для нового уровня с несколькими видами и готовой DataTable использовать `cubegrid-concept-build`.

В качестве источников методологии использованы предоставленные скиллы Radiant (`plan-describe`, `shape-build`, `shape-describe`), но BSP-специфические инструкции не переносились. Основные документы Epic:

- [CubeGrid (Unreal Engine 5.8)](https://dev.epicgames.com/documentation/unreal-engine/cubegrid-tool-in-unreal-engine?application_version=5.8&lang=en-US)
- [Data Assets](https://dev.epicgames.com/documentation/unreal-engine/data-assets-in-unreal-engine)
- [Data Driven Gameplay Elements](https://dev.epicgames.com/documentation/unreal-engine/data-driven-gameplay-elements-in-unreal-engine)
- [Blueprint Struct Variables](https://dev.epicgames.com/documentation/en-us/unreal-engine/blueprint-struct-variables-in-unreal-engine)

## Проверка

Код конвертации координат покрыт четырьмя регрессионными тестами Python. Тексты скиллов проверены на наличие всех внутренних `references/` файлов. **Проверка на запущенном Unreal Editor с реальным MCP не выполнялась**: в этой задаче доступен исходный `CubeGridToolset.h`, но нет живого подключения к редактору.
